# Landing portrait variants

The colour cutout is `ariq-arko-cutout.png`. Original photographs and the upscaled version are retained alongside it.

The previous black-and-white appearance is preserved in `lib/portfolio-styles.ts` as `hero-portrait-monochrome`. To restore it, use `portfolioClass("hero-portrait hero-portrait-monochrome")` on the landing portrait. This retains the same crop and contrast without changing the original colour image.
